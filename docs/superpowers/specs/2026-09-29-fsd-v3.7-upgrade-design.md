# Design Specification: FSD v3.7 Upgrade & Modular Integration

- **Document Name**: FSD v3.7 Feature Integration Design Document
- **Date**: 2026-09-29
- **Target Application**: Work Tracker Pro (TrackerKerja)
- **Architecture**: Decoupled React 18 SPA (Vite) Frontend + ASP.NET Core 8.0 Web API Backend + MySQL 8.x (Entity Framework Core 8 via Pomelo)
- **Status**: Approved for Implementation Planning

---

## 1. Executive Summary & Goals

This specification defines the architectural and functional upgrade of Work Tracker Pro to align with **FSD/TSD v3.7 ("Multi-Company Corporate Code Isolation, Project Finance, Admin Company Grouping & Gamification Edition")** while retaining the current modern decoupled application template (**React 18 SPA + ASP.NET Core 8.0 Web API**).

### Primary Objectives:
1. **Multi-Company Corporate Code Isolation**: Implement zero-knowledge company registration via corporate codes (`Company.Code`), tenant-scoped data queries, and dynamic tenant badges in the top navigation bar.
2. **Project Finance & Mass Task Allocation**: Track project `Budget`, `ActualCost`, financial `BurnRatePercent`, `ClientName`, `ProjectManagerId`, and provide a 1-click modal for bulk assigning loose tasks to projects.
3. **Comprehensive Gamification v3.7 Engine**:
   - Monthly check-in point balance starts from 0 at the beginning of each calendar month.
   - 15-day (50%) and 30-day (100%) point accumulation thresholds.
   - Daily check-in (+10 pts) with streak tracking and an automatic 2-day absence reset tolerance rule.
   - 30-day milestone bonus (+500 pts) and milestone-only reward access.
   - 40+ Indonesian youth-themed badges (*Si Paling Eksekutor*, *Kopi & Keringat*, *Jawara Timesheet*, etc.).
   - Reward catalog management with stock reservation, point conversion (1 pt = Rp 100), and Admin approval/rejection workflows.
   - Dashboard 5th metric card (*Daily Check-In & Streak*) and animated smart reminder banner.
4. **Member Directory & Unified Task Save**:
   - Admin-exclusive grouping of team members by company with mini-KPIs (completion ratio, hours).
   - Profile cover picture customization (`CoverPictureUrl`).
   - Permanent user deletion with dual verification for Admins.
   - Unified task save endpoint (`SaveTaskAndSession`) allowing editing task metadata and recording manual work sessions in a single atomic transaction.
5. **Security, Password Reset & Ticketing De-scoping**:
   - Self-service password reset with fallback *User Claim Link* (15 min) when SMTP is unconfigured.
   - 30-minute lockout guard after 3 consecutive failed attempts.
   - De-scope and remove Ticketing from frontend navigation, routes, and UI to achieve 100% parity with FSD v3.7.

## 4. API Endpoints & Business Logic

### 4.1 Multi-Company Corporate Code Registration
- `POST /api/auth/register`
  - Input: `FullName`, `Email`, `Password`, `JobTitle`, `CompanyOption` ("existing" | "new"), `ExistingCompanyCode`, `NewCompanyName`, `NewCompanyCode`.
  - Logic:
    - If `CompanyOption == "existing"`: Lookup `Company` by uppercase code. If not found, return 400 `"Kode perusahaan tidak valid atau belum terdaftar."`.
    - If `CompanyOption == "new"`: Validate `NewCompanyCode` (>= 3 chars, alphanumeric). Check duplicate. If unique, create new `Company` with uppercase code.
- Auth Response Payload:
  - Return `companyCode`, `companyName`, and `role` to allow React frontend to display `[KODE] Nama Perusahaan` in navbar.

### 4.2 Project Financials & Bulk Task Assignment
- `GET /api/projects`: Include `budget`, `actualCost`, `burnRatePercent`, `clientName`, `projectManagerId`, `projectManagerName`.
- `POST /api/projects/{id}/assign-tasks`:
  - Body: `{ taskIds: [1, 2, 3] }`
  - Reassigns tasks with matching IDs to `ProjectId = id`, updates `UpdatedAt`.

### 4.3 Gamification Engine v3.7
- `POST /api/gamification/check-in`:
  - Validates user has not checked in today (`DateOnly.FromDateTime(DateTime.UtcNow)`).
  - Calculates streak:
    - If `daysDiff == 1`: `StreakDay = lastCheckIn.StreakDay + 1`.
    - If `daysDiff >= 2`: `StreakDay = 1` (tolerance reset applied).
    - If first check-in: `StreakDay = 1`.
  - Monthly milestone check: If `StreakDay == 30`, sets `IsMonthlyMilestone = true` and awards 500 bonus points.
  - Automatically triggers badge evaluation (`CHECKIN_1`, `STREAK_7`, `STREAK_14`, `CHECKIN_30`, etc.).
- `GET /api/gamification/summary`:
  - Returns: `badgePoints`, `dailyCheckInPoints`, `totalEarnedPoints`, `pointsSpent`, `availablePoints`, `currentStreak`, `hasCheckedInToday`, `monthlyProgressPercent`, `rupiahEquivalent`.
  - Formula:
    $$\text{AvailablePoints} = (\text{BadgePoints} + \text{MonthlyAccumulatedCheckInPoints}) - \text{PointsSpentNonRejectedClaims}$$
- `POST /api/gamification/claim-reward`:
  - Body: `{ rewardItemId: int, userNotes: string }`
  - Validates stock > 0, available points >= `item.PointCost`. If `IsMonthlyMilestoneReward`, validates 30-day streak milestone. Decrements stock, saves claim as `Pending`.
- `POST /api/gamification/process-claim`:
  - Admin endpoint: Body `{ claimId: int, status: int, adminNotes: string }`
  - If status == `Rejected`: Restores stock (`Stock + 1`).
- `GET /api/gamification/rewards`: Returns catalog of active rewards with stock and user's past claims.

### 4.4 Member Directory & Unified Task Save
- `GET /api/members`: Admin returns grouped view with company metadata, total members, completed task ratio, and accumulated hours.
- `DELETE /api/members/{id}/permanent`: Requires Admin password and target full name confirmation.
- `POST /api/tasks/{id}/unified-save`: Accepts task fields + optional `manualHours`, `manualMinutes`, `manualSessionDate`, `manualNotes`. Atomically saves task and inserts a `WorkSession`.

### 4.5 Security & User Password Reset
- `POST /api/auth/forgot-password`: Generates reset token. If email SMTP fails or is disabled, generates an immediate claim link: `/reset-password?token=...&claim=true`.
- `POST /api/auth/reset-password`: Consumes token and updates password. Enforces 30-minute lockout on 3 consecutive failed attempts.

### 4.6 De-scoping Ticketing
- Remove `/tickets` route from `App.jsx`.
- Remove Ticketing menu item from `Sidebar.jsx`.
- Clean up any unused ticket widgets from the dashboard.

## 5. Implementation Phases

- **Phase 1: Core Database & Multi-Company Corporate Code Isolation + Project Finance & Bulk Task Assignment**
  - Update `Company`, `Project`, `ApplicationUser` entities in C#.
  - Add EF Core migrations and apply to MySQL database.
  - Update `AuthApiController` and `RegisterPage.jsx` with Zero-Knowledge registration.
  - Update `AppLayout.jsx` / `Navbar.jsx` with active tenant badge.
  - Update `ProjectsApiController` and `ProjectsPage.jsx` with financial burn rate and bulk assign modal.

  - Create `DailyCheckIn` and `RewardItem` entities, refactor `RewardClaim`.
  - Implement check-in logic, streak rules, 15/30-day accumulation, and 40+ Indonesian modern badges in `DatabaseSeeder.cs`.
  - Implement `GamificationApiController` endpoints.
  - Update `DashboardPage.jsx` with 5th metric card & Smart Reminder Banner.
  - Revamp `GamificationPage.jsx` with 30-day roadmap, rewards catalog, and claim modal.
  - Add rewards management tab in `MasterDataPage.jsx`.
- **Phase 3: Member Directory Enhancements & Unified Task Save**
  - Update `MembersPage.jsx` with Admin company grouping and cover banners.
  - Implement permanent user deletion endpoint and confirmation modal.
  - Implement `unified-save` endpoint in `TasksApiController` and integrate into task edit modal.
- **Phase 4: Security, Password Reset Claim Link & Ticketing De-scoping**
  - Implement forgot password with fallback User Claim Link and lockout guard.
  - De-scope Ticketing from frontend router (`App.jsx`) and sidebar (`Sidebar.jsx`).
  - Run full regression testing across all modules.
