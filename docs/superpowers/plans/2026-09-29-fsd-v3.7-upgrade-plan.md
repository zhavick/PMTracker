> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Work Tracker Pro with FSD/TSD v3.7 features (Multi-Company Corporate Code Isolation, Project Finance & Bulk Task Assignment, Comprehensive Gamification v3.7 with Daily Check-in & Rewards Catalog, Member Directory Admin Grouping, Self-Service Password Reset Claim Link, and Ticketing De-scoping) within the existing React 18 SPA + ASP.NET Core 8.0 Web API template.

**Architecture:** Decoupled modern web application using React 18 SPA (Vite) on the frontend communicating via RESTful API with an ASP.NET Core 8.0 backend. Persistence is managed via Entity Framework Core 8 with MySQL (Pomelo provider). Domain services encapsulate business logic for gamification streaks, point calculations, and multi-tenancy scoping.

**Tech Stack:** React 18, Vite, Tailwind/CSS Custom Tokens, Lucide Icons, ASP.NET Core 8.0 Web API, Entity Framework Core 8, Pomelo MySQL, BCrypt/PBKDF2 Identity, ClosedXML.

public async Task<IActionResult> AssignTasks(int id, [FromBody] BulkAssignTasksDto dto)

    if (dto.TaskIds == null || dto.TaskIds.Length == 0)

- [ ] **Step 1: Implement `GamificationService.cs`**

Encapsulate core rules:
- `CheckInAsync(string userId)`:
  - Check if today's check-in exists. If yes, return 400.
  - Calculate `daysDiff = (today - lastCheckIn.CheckInDate).Days`.
  - If `daysDiff == 1`: `StreakDay = lastCheckIn.StreakDay + 1`.
  - If `daysDiff >= 2`: `StreakDay = 1`.
  - If `StreakDay == 30`: Award 500 bonus points and set `IsMonthlyMilestone = true`.
- `GetPointsSummaryAsync(string userId)`:
  - Calculate:
    $$\text{AvailablePoints} = (\text{BadgePoints} + \text{MonthlyCheckInPoints}) - \text{PointsSpentNonRejectedClaims}$$
  - Calculate Rupiah conversion: `AvailablePoints * 100`.
- `ClaimRewardAsync(string userId, int rewardItemId, string userNotes)`:
  - Check item stock > 0 and available points.
  - If `IsMonthlyMilestoneReward`, verify user has achieved 30-day milestone.
  - Decrement stock (`Stock - 1`), insert `RewardClaim` with status `Pending`.
- `ProcessRewardClaimAsync(int claimId, ClaimStatus status, string adminNotes, string adminUserId)`:
  - If status == `Rejected`: increment stock (`Stock + 1`).

[HttpPost("{id}/unified-save")]
public async Task<IActionResult> UnifiedSave(int id, [FromBody] UnifiedTaskSaveDto dto)
{
    var task = await _db.Tasks.FirstOrDefaultAsync(t => t.Id == id);
    if (task == null) return NotFound();

    // Update task metadata
    task.Title = dto.Title;
    task.Description = dto.Description;
    task.Status = dto.Status;
    task.Priority = dto.Priority;
    task.Progress = dto.Progress;
    task.Obstacle = dto.Obstacle;
    task.Solution = dto.Solution;
    task.UpdatedAt = DateTime.UtcNow;

    // Optional manual session
    if (dto.ManualHours > 0 || dto.ManualMinutes > 0)
    {
        var seconds = (dto.ManualHours * 3600) + (dto.ManualMinutes * 60);
        var session = new WorkSession
        {
            TaskId = id,
            UserId = _userManager.GetUserId(User),
            StartTime = dto.ManualSessionDate ?? DateTime.UtcNow,
            EndTime = (dto.ManualSessionDate ?? DateTime.UtcNow).AddSeconds(seconds),
            Duration = seconds,
            Notes = dto.ManualNotes
        };
        _db.Sessions.Add(session);
    }

    await _db.SaveChangesAsync();
    return Ok(new { message = "Tugas dan sesi kerja berhasil disimpan." });
}
